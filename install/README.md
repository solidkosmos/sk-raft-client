#### Windows

Each client API implementation requires a different setup.
The installation script will setup all environments if no argument is given.
To only build a specific environment specify with the apropriate switch.

1. Set execution policy in Powershell

` PS> Set-ExecutionPolicy Bypass -Scope Process`

2. Execute installation Script

` PS> .\sk-setup.ps1`
